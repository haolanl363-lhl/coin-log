# 栈 · 加密交易日志

一个开源、自托管的加密交易记录网站原型，支持多用户账号、现货与合约记录、CSV 导入、持仓查看和交易复盘。USDT 为默认计价单位。

## 本地运行

需要 Python 3.10 或更新版本，不需要安装第三方依赖。

最简单的方式是在 Windows 双击 `启动网站.bat`。它会启动本地服务并自动打开网站；请保持弹出的命令窗口开启，关闭它会停止网站。

也可以在本目录打开终端后运行：

```bash
python server.py
```

打开 http://127.0.0.1:8000 ，创建账号即可使用。数据写入项目目录下的 `data/`，请定期备份该目录。

如果要让局域网内其他设备访问，可设置 `COINLOG_HOST=0.0.0.0` 后启动。公网部署前请放在启用 HTTPS 的反向代理之后，并做好数据备份。当前版本适合作为自托管原型，不建议直接承载高价值账户数据。

## 发布为公网网站（Render）

项目包含 `render.yaml`，可直接部署为 Render Web Service。提交代码到 GitHub 后，在 Render 创建 Blueprint 并选择该仓库。Render 会自动读取部署配置、提供 HTTPS 网址，并把用户数据保存到挂载磁盘。

部署配置使用 Render 免费 Web Service，并通过 `DATABASE_URL` 连接 Neon 免费 PostgreSQL。先创建 Neon 数据库，将数据库连接字符串作为 Render 的私密环境变量填写；不要把连接字符串上传到 GitHub。部署启动时会自动创建数据表。请保留 `COINLOG_SECURE_COOKIE=true`，并定期导出 CSV 备份。免费服务可能休眠，首次打开会有等待时间。

云数据库部署先运行 `pip install -r requirements.txt` 安装 PostgreSQL 驱动。本地未设置 `DATABASE_URL` 时继续使用 `data/` 文件夹；本地数据不会自动迁移到云端，可通过 CSV 导出导入迁移交易记录。账号需在云端重新注册。

## 当前支持

- 多用户注册和登录；密码使用 PBKDF2 哈希保存，用户数据按账户分文件隔离。
- 手工记录现货买入、卖出，以及合约开多、平多、开空、平空。
- 导入常见币安 CSV 导出字段，导入前显示预览；导出全量记录为 CSV。
- 总览、持仓、交易流水、按币种复盘，以及手动更新标记价格。
- 无第三方运行时依赖，源代码采用 MIT License。

## 计算口径

现货已实现盈亏使用均价法估算，扣除记录的手续费。合约已实现盈亏直接读取导入值，或由手动平仓记录填写；手续费/资金费会扣除。未实现盈亏使用用户手动填写的标记价格。不同币安导出模板的列名和数量口径可能不同，首次导入请核对预览和原始文件；目前不连接币安 API，也不会收集 API 密钥。

## 后续适配

可根据你导出的币安现货和 USDⓈ-M / COIN-M 合约 CSV 样例，完善列映射、资金费、手续费币种换算和逐仓/全仓信息。后续如接 API，建议只使用只读权限并避免保存提现权限。

## 炒股 / 炒币模式

登录后在页面顶部切换模式。A 股模式以 CNY 计价、数量以股计量；炒币模式以 USDT 计价并保留现货与合约。记录和标记价格分别保存，旧加密资产记录自动保留在炒币模式。股票 CSV 支持中文常见表头及本站导出的 CSV，导入页提供模板。标记价格手动录入，盈亏采用均价法估算。

## 日夜主题、情绪复盘与 AI

默认白天主题，登录页和工作台均可切换日夜并在当前浏览器记住选择。每笔交易可填写前后情绪、强度、计划、风险安排、执行情况和事后总结；旧记录在复盘页补填。支持 7 天、30 天、全部范围及总结导出。五项各 20 分；完整复盘才计入平均分，缺失数据不推断。分数衡量记录情况与自评，不衡量投资能力。

AI 使用硅基流动 XingChenAGI/Xing4.0-29B，2026-10-10 官网输入、输出均标注免费。API 密钥仅通过 Render 私密环境变量 SILICONFLOW_API_KEY 配置，不放入仓库或网页。配置后用户须勾选发送授权再点击生成。后台从当前账户与模式读取最多 50 笔记录，调用间隔一分钟；不发送用户名、密码或其他账户记录。模型不会自动切换到付费模型，服务失败时保留免费规则总结。免费价格和可用性以服务商当前政策为准。
